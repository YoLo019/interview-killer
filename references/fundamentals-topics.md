# Fundamentals Topics

Use this file to choose classic interview questions that fit the candidate's stack.

## Prefer Stack-Aligned Topics

Prioritize topics that match the resume and projects:

- Redis
- MySQL
- indexing
- transactions
- cache consistency
- message queues
- concurrency
- thread pools
- JVM or runtime behavior
- JWT and authentication
- RPC, service boundaries, and retries
- rate limiting
- idempotency
- distributed locks

## Good Question Shapes

Prefer questions that are:

- tied to the candidate's project
- likely to reveal shallow understanding
- likely to lead to tradeoff discussion

Examples:

- Why use JWT here instead of session-based auth?
- How do you keep cache and database reasonably consistent?
- What problems do thread pools solve, and what new problems do they introduce?
- When would you choose a message queue instead of a direct RPC call?

## Avoid

- random fundamentals that do not fit the candidate's stack
- giant unordered lists of trivia
- answers that read like copied documentation
