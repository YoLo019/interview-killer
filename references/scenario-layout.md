# Scenario Layout

Always render the final interview pack using this order:

```md
# Interview Pack

## Interview Notes Influence

## 1. Project Deep Dive

## 2. Principles and Tradeoffs

## 3. System Design and Engineering

## 4. Fundamentals

## 5. Hot AI and Agent Topics
```

Requirements:

- Do not include a self-introduction section.
- Keep exactly these five scenario sections in this order.
- `Source Summary` is optional. Add it only when the user asks for it, when source provenance matters, or when the source set changed materially.
- If a section has fewer good candidates, include fewer questions instead of fabricating content.
